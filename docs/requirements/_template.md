# 요구사항 작성 양식

영역 문서(common.md, map.md 등)의 `## 요구사항` 아래에 이 블록을 복사해 추가합니다.
새 항목은 아래쪽에 추가하고, backlog.md에도 한 줄 추가합니다.

```markdown
### REQ-XXX-000 제목 (한 줄 요약)

- 상태: 대기
- 우선순위: P1
- 등록일: YYYY-MM-DD
- 대상: `Prototype/css/style.css` `.selector` / `Prototype/js/app.js` 함수명

**현재 문제**
지금 어떻게 보이는지, 무엇이 문제인지.

**요구사항**
어떻게 바뀌어야 하는지. "~해야 한다" 형태로 구체적으로 쓴다.

**완료 조건**
- [ ] 확인 가능한 조건 1
- [ ] 확인 가능한 조건 2

**참고**
- 스크린샷: ![](../assets/xxx/REQ-XXX-000_설명.png)
- 관련: REQ-XXX-000

**작업 기록**
(완료 시 AI가 작성: 수정한 파일, 변경 요약, 남은 이슈)
```

## 작성 요령

- 요구사항 한 건에는 문제 하나만 담는다. 여러 문제면 나눈다.
- 완료 조건은 눈이나 브라우저로 확인할 수 있게 쓴다. ("예쁘게" 대신 "카드 간격 12px, 모서리 `--radius`")
- 사용자의 지적 원문이 의미가 있으면 `참고`에 인용해 둔다.
