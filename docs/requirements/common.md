**현재 문제**

**요구사항**
1. ⚙️ 버튼을 누르면 "설정·정보" 바텀시트가 열려야 한다. 버튼 이름(`aria-label`)은 `설정·정보`로 바꾼다.
2. 아이콘은 톱니바퀴를 유지하되, REQ-DS-007대로 이모지 대신 Material Symbols `settings`를 쓴다.
3. 바텀시트는 위에서부터 네 구역으로 나눈다.
   1. **글자 크기**: `보통` / `크게` / `아주 크게` 중 하나를 고른다.
      - 뿌리 글자 크기(`html`의 `font-size`)만 바꿔 앱 전체 글자가 함께 커지게 한다. (REQ-DS-004의 `rem` 단위 전제)
      - 단계 값은 보통 100%, 크게 112.5%, 아주 크게 125%를 기본으로 하고, 구현 때 화면이 깨지지 않는지 확인해 조정한다.
      - 고른 값은 다시 열어도 유지되게 브라우저에 저장한다. 기본값은 `보통`.
      - 노선도 SVG 안의 역 이름은 영향받지 않아도 된다.
   2. **답변 소리로 듣기**: `말로 물었을 때만` / `항상` / `끄기` 중 하나를 고른다. 기본값은 `말로 물었을 때만`. 고른 값은 브라우저에 저장한다. 동작은 REQ-CHAT-005를 따른다. (2026-11-11 추가)
   3. **정보**: 데이터 출처, 앱 버전, 팀 정보.
      - 노선도 출처 표시는 REQ-COM-002를 따른다.
      - 엘리베이터 정보: "엘리베이터 정보는 시연용 예시 데이터입니다."라고 밝힌다.
      - 음성 입력: "음성 입력은 브라우저의 음성 인식 기능을 쓰며, 말한 내용이 인식을 위해 외부 서버로 전송될 수 있습니다."라고 밝힌다. (REQ-CHAT-004, 2026-11-11 추가)
      - 앱 버전과 팀: 예) `엘리베이터 지하철 v0.2 · 우왕톤 7팀`
   4. **시연 제어판**: 맨 아래에 작게 둔다. 누르면 지금의 시연 제어판 내용(시나리오, 초기화, 전체화면)이 열린다. 휴대폰으로 직접 시연할 때를 위한 예비 입구다.
4. 데스크톱 폰 옆 시연 패널(`#demoPanel`)은 지금 그대로 둔다.

### REQ-COM-004 역 상세 시트를 "요약 → 펼침" 두 단계로, 지도와 함께 쓰기

- 상태: 대기
- 우선순위: P1 (제안)
- 등록일: 2026-11-11
- 대상:
  - `Prototype-v2/css/style.css` `.bottom-sheet` (`max-height: 52%`), `.sheet-backdrop`, `.sheet-handle`, `.sheet-content`
  - `Prototype-v2/js/app.js` `initSheet` (563행~, 드래그로 닫기, 막 `#sheetBackdrop` 클릭으로 닫기), `openSheetShell`, `closeSheet` (340~357행), `openStation` (`focusStation`), `renderStationSheet`
  - `Prototype-v2/js/metro-map.js` `handleTap` (568행, 역/빈 곳 탭), `onDown`/`endPointer` (드래그 판정), `focusStation`

**현재 문제**
- 역 상세 시트 높이가 화면의 52%로 고정되어 있고, 아래로 끌어 닫는 것만 된다. 글자를 키우면(REQ-DS-004) 엘리베이터 목록은 좁은 칸 안에서 스크롤해야 한다.
- 시트가 열리면 지도 위에 반투명 막(`#sheetBackdrop`)이 덮여 지도를 움직일 수 없다. 지도를 만지면 시트가 바로 닫혀 보던 역 정보가 사라진다.

**요구사항**
1. 역 상세 시트는 두 단계 높이를 가진다.
   - `요약`: 역을 누르면 처음 열리는 높이. 화면의 약 4분의 1. 다음만 보여 준다.
     - 역 이름 + 노선 뱃지
     - 운행 현황 막대 (REQ-COM-007)
     - 문제 있는 역(일부 운행, 이용 불가)이면 `우회 경로 보기` 버튼 하나 (REQ-COM-006의 강조 버튼)
   - `펼침`: 상단 검색창 아래까지 올라오는 높이. 대체역 안내, 엘리베이터 목록, 출발 시각 계산 등 전체 내용을 본다.
   - 요약 상태에서도 지도에서 선택한 역이 시트에 가려지지 않게 지도를 맞춘다. (`focusStation`)
2. 시트 단계 바꾸기
   - 손잡이나 시트 머리 부분을 위로 끌면 `펼침`, 아래로 끌면 `요약`.
   - `요약`에서 더 아래로 끌면 닫힌다. **닫기는 아래로 끌기로만 한다.**
   - 손잡이를 누르면 `요약` ↔ `펼침`이 바뀐다.
   - `요약`에서 시트 내용을 위로 밀면 `펼침`으로 올라간다. `펼침`에서는 내용이 스크롤된다.
3. 시트가 열려 있을 때 지도에서 한 동작

   | 지도에서 한 동작 | 시트 |
   |---|---|
   | 끌어서 이동, 확대·축소(핀치, 휠, 줌 버튼) | 그대로 둔다 |
   | 빈 곳을 톡 누름 | `펼침`이면 `요약`으로 내려간다. `요약`이면 그대로 둔다 |
   | 다른 역을 누름 | 시트 내용이 그 역으로 바뀐다. 단계는 `요약` |

   - 빈 곳을 눌러도 닫지 않는 이유: 손 떨림이 있는 사용자가 실수로 지도를 건드려도 보던 역 정보가 사라지지 않게 하기 위해서다.
4. `요약`일 때는 지도 위 반투명 막을 없애 지도를 그대로 쓸 수 있게 한다. `펼침`일 때 막을 둘지는 구현 때 화면을 보고 정하되, 막을 두더라도 막을 누르면 `요약`으로 내려가야 한다. (닫히지 않음)
5. 손잡이는 누를 수 있는 영역이 44px 이상이고, 화면 읽기 프로그램용 이름(`시트 펼치기` / `시트 접기`)이 있다. 키보드 `Esc`는 지금처럼 시트를 닫는다.
6. 다른 바텀시트(설정·정보, 시연 제어판, 출발계산의 역 검색 REQ-TIME-001)는 요약 단계 없이 내용 높이만큼(최대 `펼침` 높이) 열리고, 아래로 끌거나 바깥을 누르면 닫힌다.
7. 움직임은 기존 `--ease-sheet`를 쓰고, "움직임 줄이기" 설정에서는 애니메이션 없이 바로 바뀐다.

**완료 조건**
- [ ] 역을 누르면 시트가 요약 높이로 열리고, 역 이름, 노선 뱃지, 운행 현황 막대가 보인다. 지도에서 선택한 역은 시트에 가려지지 않는다.
- [ ] 문제 있는 역의 요약에는 `우회 경로 보기` 버튼이 보이고, 정상 역의 요약에는 버튼이 없다.
- [ ] 위로 끌거나 손잡이를 누르면 펼침이 되고, 아래로 끌면 요약으로 돌아온다. 요약에서 더 끌면 닫힌다.
- [ ] 요약 상태에서 지도를 끌고 확대·축소해도 시트가 그대로 있다.
- [ ] 펼침 상태에서 지도 빈 곳을 누르면 요약으로 내려가고, 닫히지 않는다.
- [ ] 시트가 열린 채 다른 역을 누르면 그 역의 요약으로 바뀐다.
- [ ] 손잡이의 누르는 영역이 44px 이상이다.
- [ ] 글자 크기 `아주 크게`(REQ-COM-001)에서 요약에 역 이름과 운행 현황이 잘리지 않고, 펼침에서 엘리베이터 목록을 편하게 볼 수 있다.
- [ ] 설정·정보, 시연 제어판은 요약 단계 없이 열리고, 아래로 끌거나 바깥을 누르면 닫힌다.

**참고**

### REQ-COM-007 역 상세 맨 위에 엘리베이터 운행 현황 막대 표시

- 상태: 대기
- 우선순위: P1 (제안)
- 등록일: 2026-11-11
- 대상:
  - `Prototype-v2/js/app.js` `renderStationSheet`의 헤더 (390~395행: `statusPill(status)`, "엘리베이터 n대 중 n대 이용 불가" 문구)
  - `Prototype-v2/css/style.css` `.sheet-header`, `.sheet-header .status-pill`

**현재 문제**
"지금 이 역 엘리베이터를 탈 수 있나?"에 대한 답이 작은 상태 뱃지(`일부 이용 불가`)와 회색 글씨("엘리베이터 4대 중 1대 이용 불가")뿐이라 한눈에 들어오지 않는다.

**요구사항**
1. 역 이름 바로 아래에 운행 현황을 보여 준다. 지금의 상태 뱃지와 회색 문구를 이것으로 바꾼다.
   ```
   (!) 일부 운행                3 / 4대
   [■■■■■■|■■■■■■|■■■■■■|╱╱╱╱╱╱]
   ```
2. 왼쪽: 상태 아이콘(REQ-DS-003) + 짧은 상태 이름. 이름은 노선도 범례(REQ-MAP-003)와 같은 말을 쓴다: `정상` / `일부 운행` / `이용 불가`.
3. 오른쪽: `운행 대수 / 전체 대수` + `대`를 크게(`--fs-title` 이상) 쓴다.
4. 아래: 엘리베이터 한 대를 한 칸으로 나눈 막대.
   - 운행 중인 칸은 `--ok`로 채운다.
   - 멈춘 칸(이용 불가, 점검)은 상태색 + 빗금 무늬로 채운다. 색만으로 구분하지 않기 위해서다. (REQ-DS-003)
   - 칸 순서는 운행 중 → 멈춤이다.
   - 엘리베이터가 많아 칸이 너무 좁아지면(구현 때 기준을 정함) 칸 구분 없이 비율 막대로 그린다.
5. 문장으로 풀어 쓴 설명("엘리베이터로 이동할 수 있어요" 등)은 쓰지 않는다.
6. 정보 없는 역: 막대와 숫자 없이 `정보 없음` 아이콘과 이름만 보여 준다.
7. 화면 읽기 프로그램에는 "엘리베이터 4대 중 3대 운행 중, 1대 멈춤"처럼 한 문장으로 읽히게 한다.

**완료 조건**
- [ ] 역 이름 아래에 상태 아이콘 + 상태 이름, 운행 대수/전체 대수, 칸 막대가 있다.
- [ ] 상태 이름이 노선도 범례와 같은 말(`정상` / `일부 운행` / `이용 불가` / `정보 없음`)이다.
- [ ] 막대 칸 수가 그 역의 엘리베이터 대수와 같고, 멈춘 칸 수가 이용 불가·점검 대수와 같다.
- [ ] 멈춘 칸은 빗금 무늬가 있어 흑백으로 봐도 구분된다.
- [ ] 정보 없는 역은 막대와 숫자가 없다.
- [ ] 시연 제어판으로 엘리베이터를 고장 내면 막대와 숫자가 바로 바뀐다.
- [ ] 화면 읽기 프로그램에서 운행 현황이 한 문장으로 읽힌다.

**참고**
