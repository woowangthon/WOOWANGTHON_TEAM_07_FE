- 우선순위: P1 (제안)

**현재 문제**
검색창 옆 ⚙️를 누르면 시연 제어판(고장 시나리오, 초기화, 전체화면)이 바텀시트로 열린다. 발표는 데스크톱 폰 프레임으로 하고 같은 제어판이 폰 옆 패널(`#demoPanel`)에 이미 있어서 중복이다. 심사위원이 보는 폰 화면에 "시연 제어판"이 나오면 실제 앱이 아니라 데모처럼 보인다.

**요구사항**
1. ⚙️ 버튼을 누르면 "설정·정보" 바텀시트가 열려야 한다. 버튼 이름(`aria-label`)은 `설정·정보`로 바꾼다.
2. 아이콘은 톱니바퀴를 유지하되, REQ-DS-007대로 이모지 대신 Material Symbols `settings`를 쓴다.
3. 바텀시트는 위에서부터 네 구역으로 나눈다.
   1. **글자 크기**: `보통` / `크게` / `아주 크게` 중 하나를 고른다.
      - 뿌리 글자 크기(`html`의 `font-size`)만 바꿔 앱 전체 글자가 함께 커지게 한다. (REQ-DS-004의 `rem` 단위 전제)
      - 단계 값은 보통 100%, 크게 112.5%, 아주 크게 125%를 기본으로 하고, 구현 때 화면이 깨지지 않는지 확인해 조정한다.
      - 고른 값은 다시 열어도 유지되게 브라우저에 저장한다. 기본값은 `보통`.
      - 노선도 SVG 안의 역 이름은 영향받지 않아도 된다.
   2. **답변 소리로 듣기**: `말로 물었을 때만` / `항상` / `끄기` 중 하나를 고른다. 기본값은 `말로 물었을 때만`. 고른 값은 브라우저에 저장한다. 동작은 REQ-CHAT-005를 따른다. (2026-11-11 추가)
   3. **정보**: 데이터 출처, 앱 버전, 팀 정보.
      - 노선도 출처 표시는 REQ-COM-002를 따른다.
      - 엘리베이터 정보: "엘리베이터 정보는 시연용 예시 데이터입니다."라고 밝힌다.
      - 음성 입력: "음성 입력은 브라우저의 음성 인식 기능을 쓰며, 말한 내용이 인식을 위해 외부 서버로 전송될 수 있습니다."라고 밝힌다. (REQ-CHAT-004, 2026-11-11 추가)
      - 앱 버전과 팀: 예) `엘리베이터 지하철 v0.2 · 우왕톤 7팀`
   4. **시연 제어판**: 맨 아래에 작게 둔다. 누르면 지금의 시연 제어판 내용(시나리오, 초기화, 전체화면)이 열린다. 휴대폰으로 직접 시연할 때를 위한 예비 입구다.
4. 데스크톱 폰 옆 시연 패널(`#demoPanel`)은 지금 그대로 둔다.

### REQ-COM-004 역 상세 시트를 "요약 → 펼침" 두 단계로, 지도와 함께 쓰기

- 상태: 완료
- 우선순위: P1 (제안)
- 등록일: 2026-11-11
- 대상:
  - `Prototype-v2/css/style.css` `.bottom-sheet` (`max-height: 52%`), `.sheet-backdrop`, `.sheet-handle`, `.sheet-content`
  - `Prototype-v2/js/app.js` `initSheet` (563행~, 드래그로 닫기, 막 `#sheetBackdrop` 클릭으로 닫기), `openSheetShell`, `closeSheet` (340~357행), `openStation` (`focusStation`), `renderStationSheet`
  - `Prototype-v2/js/metro-map.js` `handleTap` (568행, 역/빈 곳 탭), `onDown`/`endPointer` (드래그 판정), `focusStation`

**현재 문제**
- 역 상세 시트 높이가 화면의 52%로 고정되어 있고, 아래로 끌어 닫는 것만 된다. 글자를 키우면(REQ-DS-004) 엘리베이터 목록은 좁은 칸 안에서 스크롤해야 한다.
- 시트가 열리면 지도 위에 반투명 막(`#sheetBackdrop`)이 덮여 지도를 움직일 수 없다. 지도를 만지면 시트가 바로 닫혀 보던 역 정보가 사라진다.

**요구사항**
1. 역 상세 시트는 두 단계 높이를 가진다.
   - `요약`: 역을 누르면 처음 열리는 높이. 화면의 약 4분의 1. 다음만 보여 준다.
     - 역 이름 + 노선 뱃지
     - 운행 현황 막대 (REQ-COM-007)
     - 문제 있는 역(일부 운행, 이용 불가)이면 `우회 경로 보기` 버튼 하나 (REQ-COM-006의 강조 버튼)
   - `펼침`: 상단 검색창 아래까지 올라오는 높이. 대체역 안내, 엘리베이터 목록, 출발 시각 계산 등 전체 내용을 본다.
   - 요약 상태에서도 지도에서 선택한 역이 시트에 가려지지 않게 지도를 맞춘다. (`focusStation`)
2. 시트 단계 바꾸기
   - 손잡이나 시트 머리 부분을 위로 끌면 `펼침`, 아래로 끌면 `요약`.
   - `요약`에서 더 아래로 끌면 닫힌다. **닫기는 아래로 끌기로만 한다.**
   - 손잡이를 누르면 `요약` ↔ `펼침`이 바뀐다.
