## 요구사항

### REQ-COM-001 ⚙️ 버튼을 "설정·정보" 화면으로 변경

- 상태: 대기
- 우선순위: P1 (제안)
- 등록일: 2026-11-11
- 대상:
  - `Prototype-v2/index.html` `#demoBtn` (`aria-label="시연 제어판"`)
  - `Prototype-v2/js/app.js` `renderDemoSheet`, `openDemoSheet`, `refreshSheet`, `sheet.mode === 'demo'`, `#demoBtn` 클릭 처리(1103행), `onSheetAction`의 `demo-*` 동작
  - `Prototype-v2/css/style.css` `:root` / `html` (글자 크기 단계 적용)

**현재 문제**
검색창 옆 ⚙️를 누르면 시연 제어판(고장 시나리오, 초기화, 전체화면)이 바텀시트로 열린다. 발표는 데스크톱 폰 프레임으로 하고 같은 제어판이 폰 옆 패널(`#demoPanel`)에 이미 있어서 중복이다. 심사위원이 보는 폰 화면에 "시연 제어판"이 나오면 실제 앱이 아니라 데모처럼 보인다.

**요구사항**
1. ⚙️ 버튼을 누르면 "설정·정보" 바텀시트가 열려야 한다. 버튼 이름(`aria-label`)은 `설정·정보`로 바꾼다.
2. 아이콘은 톱니바퀴를 유지하되, REQ-DS-007대로 이모지 대신 Material Symbols `settings`를 쓴다.
3. 바텀시트는 위에서부터 세 구역으로 나눈다.
   1. **글자 크기**: `보통` / `크게` / `아주 크게` 중 하나를 고른다.
      - 뿌리 글자 크기(`html`의 `font-size`)만 바꿔 앱 전체 글자가 함께 커지게 한다. (REQ-DS-004의 `rem` 단위 전제)
      - 단계 값은 보통 100%, 크게 112.5%, 아주 크게 125%를 기본으로 하고, 구현 때 화면이 깨지지 않는지 확인해 조정한다.
      - 고른 값은 다시 열어도 유지되게 브라우저에 저장한다. 기본값은 `보통`.
      - 노선도 SVG 안의 역 이름은 영향받지 않아도 된다.
   2. **정보**: 데이터 출처, 앱 버전, 팀 정보.
      - 노선도 출처 표시는 REQ-COM-002를 따른다.
      - 엘리베이터 정보: "엘리베이터 정보는 시연용 예시 데이터입니다."라고 밝힌다.
      - 앱 버전과 팀: 예) `엘리베이터 지하철 v0.2 · 우왕톤 7팀`
   3. **시연 제어판**: 맨 아래에 작게 둔다. 누르면 지금의 시연 제어판 내용(시나리오, 초기화, 전체화면)이 열린다. 휴대폰으로 직접 시연할 때를 위한 예비 입구다.
4. 데스크톱 폰 옆 시연 패널(`#demoPanel`)은 지금 그대로 둔다.

**완료 조건**
- [ ] ⚙️를 누르면 "설정·정보" 바텀시트가 열리고, 다시 누르거나 바깥을 누르면 닫힌다.
- [ ] 버튼 아이콘이 이모지가 아닌 Material Symbols `settings`이고, `aria-label`이 `설정·정보`다.
- [ ] 구역 순서가 `글자 크기 → 정보 → 시연 제어판`이다.
- [ ] 글자 크기를 바꾸면 4개 탭과 바텀시트의 글자가 즉시 함께 바뀐다.
- [ ] `아주 크게`에서도 375px 폭에서 탭바, 필터 바, 버튼 글자가 잘리거나 겹치지 않는다.
- [ ] 새로고침해도 고른 글자 크기가 유지된다.
- [ ] 정보 구역에 노선도 출처(REQ-COM-002), 엘리베이터 예시 데이터 안내, 앱 버전과 팀이 있다.
- [ ] 시연 제어판 항목에서 시나리오 5개, 초기화, 전체화면이 지금처럼 동작한다.
- [ ] 데스크톱 옆 시연 패널이 지금처럼 동작한다.

**참고**
- 결정: 2026-11-11 추천안으로 결정. ("추천으로 해줘") 탈락 안: B안 "출처를 노선도 구석에 표시하고 ⚙️ 제거"(지도를 가리고 13px 미만 글자 필요), C안 "ⓘ 정보 버튼"(접근성 설정 자리가 없음).
- 아이콘: 사용자가 "원래 것보다 깔끔한 걸로" 요청 → 톱니바퀴 모양 유지, 이모지 대신 단색 선 아이콘으로 결정.
- 엘리베이터 데이터 출처: 발표 때 실제 데이터로 오해받지 않도록 예시 데이터임을 밝히기로 결정.
- 관련: REQ-COM-002, REQ-DS-004, REQ-DS-007

### REQ-COM-002 노선도 출처(공공누리 제1유형) 표시

- 상태: 대기
- 우선순위: P0 (제안: 공개 전 필수)
- 등록일: 2026-11-11
- 대상: REQ-COM-001의 "설정·정보" 바텀시트 `정보` 구역 (`Prototype-v2/js/app.js`)

**현재 문제**
노선도(REQ-MAP-001)는 서울교통공사 「수도권 지하철 노선도」(공공누리 제1유형)를 바탕으로 그렸다. 제1유형은 출처를 표시해야 쓸 수 있는데, 지금 앱 어디에도 출처가 없다.

**요구사항**
1. "설정·정보" 바텀시트의 `정보` 구역에 다음 문구를 넣어야 한다.
   > 이 노선도는 서울교통공사에서 공공누리 제1유형으로 개방한 '수도권 지하철 노선도'를 이용하였으며(일부 변경), 해당 저작물은 서울교통공사 홈페이지에서 무료로 내려받을 수 있습니다.
2. 문구 옆이나 위에 공공누리 제1유형 마크를 붙인다. 마크 이미지는 공공누리 공식 배포 이미지를 내려받아 프로젝트 안에 두고 쓴다.
3. 글자 크기는 REQ-DS-004의 `--fs-caption`(13px) 이상이다.
4. 노선도 화면에는 출처를 넣지 않는다. (REQ-MAP-001 요구사항 5와 일치)

**완료 조건**
- [ ] "설정·정보" 바텀시트에 위 문구가 그대로 있다.
- [ ] 공공누리 제1유형 마크가 보인다.
- [ ] 출처 글자가 13px 이상이다.
- [ ] 노선도 화면에는 출처 표시가 없다.

**참고**
- 메모 출처: REQ-MAP-001 `참고`의 "메모 (출처 표시, 미등록)"를 이 요구사항으로 등록함.
- 우선순위 근거: 시연 자체에는 지장이 없지만 저작물 이용 조건이라 공개 전 반드시 필요해서 P0으로 제안.
- 관련: REQ-MAP-001, REQ-COM-001
