### REQ-MAP-001 노선도를 서울교통공사 공식 노선도 배치로 교체

- 상태: 완료
- 우선순위: P1
- 등록일: 2026-11-06
- 대상: `Prototype/js/mock-data.js` `stations[].x`, `stations[].y`, `lines` / `Prototype/js/metro-map.js` `buildRiver`, `buildLines`, `buildStations`
- 구현 위치: `Prototype-v2/` (v1 `Prototype/`은 그대로 둠)

**현재 문제**
노선도가 실제 역 위치(지리 좌표)를 비율대로 줄여 그린 지도다. 도심(시청, 종로, 강남 등)에 역이 몰려 모바일 화면에서 역 이름이 겹치고, 사람들이 익숙한 지하철 노선도 모양과 달라 바로 읽히지 않는다.

**요구사항**
1. 역 위치와 노선 모양을 서울교통공사 「수도권 지하철 노선도」(공공누리 제1유형) 배치대로 바꿔야 한다.
   - 원본: `docs/assets/map/REQ-MAP-001_공식노선도_원본.pdf`
   - 각 역의 상대 위치(위아래, 좌우, 간격)와 노선이 꺾이는 각도를 원본과 같게 맞춘다.
2. 대상 노선은 **1~8호선**이다. 나머지 노선은 앱 전체에서 뺀다. (REQ-MAP-002)
3. 한강도 원본 노선도에 그려진 모양과 위치를 따라야 한다. 지금처럼 역 좌표 사이 중간점을 이어 그리는 방식(`buildRiver`)은 쓰지 않는다.
4. 엘리베이터 상태 표시(역 마커 색), 역 탭, 줌, 이동, 우회 경로 하이라이트 등 지금 노선도의 기능은 그대로 동작해야 한다.
5. 출처 표시는 이 요구사항에서 하지 않는다. 노선도 화면에도 넣지 않는다. (아래 `참고`의 메모 참고)

**완료 조건**
- [x] 1~8호선의 모든 역이 원본 노선도와 같은 상대 위치에 있다. (원본 이미지와 나란히 놓고 비교했을 때 역 순서, 방향, 꺾이는 곳이 같다)

- [x] 환승역(예: 시청, 동대문역사문화공원, 왕십리)이 노선마다 따로 찍히지 않고 하나의 역으로 표시된다.

### REQ-MAP-003 역 노드 자체로 엘리베이터 상태 표시

- 상태: 대기
- 우선순위: P1 (제안)
- 등록일: 2026-11-11
- 대상:
  - `Prototype-v2/js/metro-map.js` `buildStations` (`st-circle`, `status-pulse`, `status-dot` 생성, 458~465행), `refreshStatuses` (625~638행), `STATUS_CLASS` (70행)
  - `Prototype-v2/css/map.css` `.st-circle`, `.station-node.transfer .st-circle`, `.station-node.st-bad .st-circle` (158~165행), `.status-dot`, `.status-pulse`, `@keyframes mm-pulse` (254행), `@media (prefers-reduced-motion: reduce)` (275행), `.map-legend`, `.map-legend .dot`
  - `Prototype-v2/index.html` `.map-legend`

**현재 문제**
엘리베이터 상태가 역 옆에 붙은 지름 3~4px짜리 색 점으로만 표시된다.
- 정상 역 60곳에 초록 점이 깔려 있어, 정작 문제 있는 역 8곳(주황 점)이 그 사이에 묻힌다.
- 정상 역과 정보 없는 역(170곳)의 차이가 작은 점 하나뿐이라 알아보기 어렵다.
- 색으로만 구분해서 색약 사용자는 상태를 알 수 없다.
- 이용 불가 역 둘레에 퍼지는 고리 효과가 끝없이 반복된다.

**요구사항**
1. 역 옆의 상태 점(`status-dot`)을 없애고, 역 노드 자체의 모양으로 상태를 보여 줘야 한다.

   | 상태 | 노드 모양 | 눈에 띄는 정도 |
   |---|---|---|
   | 정보 없음 | 속이 빈 흰 원 + 노선 색 테두리 (지금 모양) | 가장 약함 |
   | 정상 | 속이 초록(`--ok`)으로 꽉 찬 원 + 노선 색 테두리 | 중간 |
   | 일부 운행 | 커진 원, 주황(`--warn`) 채움 + 흰색 `error`(!) 아이콘 | 가장 강함 |
   | 이용 불가 | 커진 원, 빨강(`--bad`) 채움 + 흰색 `cancel`(✕) 아이콘 | 가장 강함 |

2. 노선 색 테두리는 모든 상태에서 남긴다. 몇 호선 역인지 계속 알 수 있어야 한다. 환승역은 지금처럼 진한 테두리를 쓰되 채움과 아이콘 규칙은 같다.

- [ ] 시연 시나리오로 역을 고장 내면 배지 숫자가 바로 늘어나고, 버튼을 누르면 그 역도 화면에 포함된다.
- [ ] 문제 역이 없을 때 배지가 없고, 누르면 토스트가 뜬다.
- [ ] 노선을 고른 상태에서는 그 노선의 문제 역만 화면에 맞춘다.
- [ ] 화면 읽기 프로그램에서 버튼 이름이 `고장·점검 역 모두 보기`로 읽힌다.
