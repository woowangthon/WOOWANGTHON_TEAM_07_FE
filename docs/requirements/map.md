## 요구사항

### REQ-MAP-001 노선도를 서울교통공사 공식 노선도 배치로 교체

- 상태: 완료
- 우선순위: P1
- 등록일: 2026-11-06
- 대상: `Prototype/js/mock-data.js` `stations[].x`, `stations[].y`, `lines` / `Prototype/js/metro-map.js` `buildRiver`, `buildLines`, `buildStations`
- 구현 위치: `Prototype-v2/` (v1 `Prototype/`은 그대로 둠)

**현재 문제**
노선도가 실제 역 위치(지리 좌표)를 비율대로 줄여 그린 지도다. 도심(시청, 종로, 강남 등)에 역이 몰려 모바일 화면에서 역 이름이 겹치고, 사람들이 익숙한 지하철 노선도 모양과 달라 바로 읽히지 않는다.

**요구사항**
1. 역 위치와 노선 모양을 서울교통공사 「수도권 지하철 노선도」(공공누리 제1유형) 배치대로 바꿔야 한다.
   - 원본: `docs/assets/map/REQ-MAP-001_공식노선도_원본.pdf`
   - 각 역의 상대 위치(위아래, 좌우, 간격)와 노선이 꺾이는 각도를 원본과 같게 맞춘다.
2. 대상 노선은 **1~8호선**이다. 나머지 노선은 앱 전체에서 뺀다. (REQ-MAP-002)
3. 한강도 원본 노선도에 그려진 모양과 위치를 따라야 한다. 지금처럼 역 좌표 사이 중간점을 이어 그리는 방식(`buildRiver`)은 쓰지 않는다.
4. 엘리베이터 상태 표시(역 마커 색), 역 탭, 줌, 이동, 우회 경로 하이라이트 등 지금 노선도의 기능은 그대로 동작해야 한다.
5. 출처 표시는 이 요구사항에서 하지 않는다. 노선도 화면에도 넣지 않는다. (아래 `참고`의 메모 참고)

**완료 조건**
- [x] 1~8호선의 모든 역이 원본 노선도와 같은 상대 위치에 있다. (원본 이미지와 나란히 놓고 비교했을 때 역 순서, 방향, 꺾이는 곳이 같다)
- [x] 노선이 원본처럼 가로, 세로, 45° 대각선으로 그려진다.
- [x] 2호선 순환선이 닫힌 모양으로 그려지고, 성수지선과 신정지선이 원본 위치에 있다.
- [x] 환승역(예: 시청, 동대문역사문화공원, 왕십리)이 노선마다 따로 찍히지 않고 하나의 역으로 표시된다.
- [x] 한강이 원본 노선도의 모양과 위치로 그려진다.
- [x] 기본 줌에서 환승역 이름이 서로 겹치지 않는다.
- [x] 역 탭, 줌 버튼 3개, 드래그 이동, 핀치 줌, 엘리베이터 상태 색, 우회 경로 하이라이트가 모두 바뀌기 전처럼 동작한다. (핀치 줌은 코드 변경 없음, 터치 기기에서는 미확인)

**참고**
- 사용자 원문: "기존에 있는 지하철 노선도에 노드를 따와서 노선도를 바꾸는 건 어때? 지금 프로토타입은 실제 역 위치를 이은 노선도이거든." → 논의 후 A안(공식 노선도 배치를 그대로 따름)으로 결정.
- 저작권: 서울교통공사_수도권 지하철 노선도는 공공누리 제1유형(출처표시, 상업적 이용 및 변경 가능)이다. 출처 표시만 하면 그대로 쓰거나 고쳐 쓸 수 있다.
- 구현 참고: 지금 노선은 역 좌표만 이어서 그린다(`lines[].segments`는 역 ID 목록). 원본처럼 역과 역 사이에서 꺾이는 곳이 있으면 꺾이는 점을 넣을 수 있게 데이터 구조를 늘려도 된다.
- 원본 PDF 좌표는 페이지 단위다. 지금 지도 단위로 옮길 때 비율을 하나로 맞춰 변환한다.

- 메모 (출처 표시, 미등록): 공공누리 제1유형이라 출처 표시는 앱 공개 전에 반드시 해야 한다. 위치는 검색창 옆 ⚙️ 버튼(`#demoBtn`)에 정보 메뉴를 넣는 방향으로 생각 중이다. ⚙️ 버튼을 앞으로 어떻게 쓸지 정한 뒤 공통 요소(`REQ-COM`)로 등록한다.
- 관련: REQ-MAP-002

**작업 기록**
- 2026-11-06 (v2 프로토타입으로 구현)
  - 새 폴더 `Prototype-v2/`: v1 `Prototype/`을 복사한 뒤 수정. v1은 그대로 둠.
  - `Prototype-v2/js/mock-data.js`: 역 238개의 `x`, `y`를 원본 PDF 좌표로 교체 (지도 좌표 = PDF 좌표 - (305, 332), 축척 1:1). 환승역은 원본 환승 표시(캡슐)의 중심점을 씀. `viewBox`를 1939×1764로 변경. 노선마다 `paths`(원본 노선 모양 SVG path) 추가. `river`(원본 한강 윤곽 path, 라벨 위치) 추가.

### REQ-MAP-002 1~8호선 외 노선과 역을 앱 전체에서 제거

- 상태: 진행중
- 우선순위: P1
- 등록일: 2026-11-06
- 대상: `Prototype/js/mock-data.js` `lines`, `stations`, `elevators`, `headways`, `firstTrain`, `lastTrain`, `timing` / `Prototype/js/app.js` `initLineFilter`

**현재 문제**
목업 데이터에 1~8호선 외에 9호선(`9`), 신분당선(`SB`), 수인분당선(`SU`), 공항철도(`AREX`), 경의중앙선(`GJ`)이 들어 있다. 노선도를 1~8호선만 공식 노선도 배치로 바꾸기로 해서(REQ-MAP-001), 이 노선들은 앱에서 빼기로 했다.

**요구사항**
1. 노선 `9`, `SB`, `SU`, `AREX`, `GJ`를 `lines`에서 지워야 한다.
2. 이 노선에만 있는 역(52개)을 `stations`에서 지워야 한다. 해당 역의 `elevators` 데이터도 함께 지운다.
   - 신방화 마곡나루 양천향교 가양 증미 등촌 염창 신목동 선유도 국회의사당 샛강 노들 흑석 구반포 신반포 사평 신논현 언주 선정릉 삼성중앙 봉은사 삼전 석촌고분 송파나루 한성백제 둔촌오륜 중앙보훈병원 양재시민의숲 청계산입구 판교 정자 서울숲 압구정로데오 한티 구룡 개포동 대모산입구 가천대 태평 야탑 이매 서현 수내 수색 가좌 서강대 서빙고 한남 응봉 중랑 망우 신촌(경의중앙)
3. 1~8호선과 이 노선이 만나는 환승역(31개)은 남기고, 역의 `lines` 목록에서 빠진 노선만 지운다.
   - 왕십리 종합운동장 선릉 강남 당산 홍대입구 회기 청량리 서울역 용산 노량진 옥수 신사 고속터미널 양재 도곡 수서 이촌 동작 김포공항 여의도 공덕 올림픽공원 디지털미디어시티 효창공원앞 상봉 강남구청 논현 석촌 복정 모란
4. 배차 간격, 첫차, 막차 같은 시간 데이터에서 빠진 노선 항목을 지운다.
5. 노선 필터, 엘리베이터 목록, 검색, 출발계산, AI 챗봇 어디에도 빠진 노선이나 역이 나오지 않아야 한다.

**완료 조건**
