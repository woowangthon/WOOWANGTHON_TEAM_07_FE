### REQ-TIME-001 출발역·도착역을 검색해서 고르기

  - 재사용 후보: `Prototype-v2/js/app.js` `searchStations`, `normalizeName` (257~278행, 상단 검색)

**현재 문제**
출발역과 도착역을 기본 드롭다운(`<select>`)에서 고른다. 238개 역을 스크롤해서 찾아야 하고, 칸이 좁아 "신도림역 (…"처럼 이름이 잘린다.

**요구사항**
1. 출발역, 도착역 칸을 누르면 역 검색 바텀시트가 열려야 한다.
   - 맨 위에 검색창이 있고, 열리자마자 입력할 수 있다.
   - 역 이름 일부만 입력해도 결과가 나온다. (상단 검색과 같은 검색 규칙)
   - 결과 한 줄: 역 이름 + 노선 뱃지 + 엘리베이터 상태 아이콘(REQ-DS-003)
   - 검색 전에는 최근 고른 역(최대 5개)을 보여 준다. 최근 기록이 없으면 안내 문구를 보여 준다.
   - 결과를 누르면 그 역이 칸에 들어가고 시트가 닫힌다.
2. 칸에는 역 이름과 노선 뱃지가 잘리지 않게 들어간다. 길면 역 이름만 말줄임한다.
3. 출발·도착 바꾸기(`⇅`), 역 상세의 `이 역까지 출발 시각 계산`, 챗봇에서 넘어오는 값 채우기는 지금처럼 동작한다.
4. 출발역과 도착역이 같으면 지금처럼 안내한다.
5. 최근 고른 역은 브라우저에 저장한다.

**완료 조건**
- [x] 출발역, 도착역 칸을 누르면 검색창이 있는 바텀시트가 열리고 바로 입력할 수 있다.
- [x] "신도"를 입력하면 신도림역이 나오고, 누르면 칸에 들어간다.
- [x] 결과에 노선 뱃지와 엘리베이터 상태 아이콘이 보인다.
- [x] 한 번 고른 역이 다음에 열 때 최근 목록에 나온다.
- [x] 375px 폭에서 칸 안의 역 이름이 "신도림역 (…"처럼 잘리지 않는다.
- [x] `⇅`, 역 상세의 `이 역까지 출발 시각 계산`, 챗봇에서 넘어오기가 바뀌기 전처럼 동작한다.

### REQ-TIME-005 출발계산 탭의 "출발 시각 계산" 제목 없애기
