# #43 디자인 보존 재통합 계획 (#66)

목표는 #43 사용자의 디자인 수정과 이전 기능 변경을 최종 main에 함께 남기는 것이다. 사용자 요청은 새 PR 생성과 검증 후 병합을 포함한다.
