## 검증과 범위

최종 실행 수치는 이 문서 아래에 기록한다. Node 정책/서비스 테스트, Chromium 디자인 보존, 계정/필터, 최신 즐겨찾기, 출발 그래픽, 접근성 조건/만료를 별도로 실행한다. 이전 브랜치의 173개 통과 기록을 이 통합본의 실행 결과로 재사용하지 않는다. 원래 native 입력/오래된 시트 선택자를 전제한 테스트 대신 보존한 AMPM/시트 인터페이스를 검증한다.

검증 중 요약 순서, 즐겨찾기 닫기, 초기 ArrowUp, 비동기 로그인 복구 필터, 필터 결과 없음 문구, 정보 없는 역을 모두 정상이라고 말하는 문구를 수정했다. 폰트 미로딩 아이콘/최대 글자 범례도 보완했다.

실제 경로 API는 미연동이고 기본 결과는 확인 필요다. 방향별 운행·복귀·승강장/환승/출구 접근성의 실제 검증은 공급자 데이터가 필요하다. 공급할 필드는 [API 협의 초안](accessible-route-api-proposal.md)에 있다. 실제 OAuth·위치 API·현장 이동·Safari/Firefox는 검증하지 않았다. BE 저장소·GitHub는 변경하지 않았다.

## 병합 절차

새 통합 브랜치 feature/66-preserve-design-integration은 디자인 af6155b에서 분기했다. 검증 후 #43을 head 고정으로 먼저 병합하고, 새 PR을 main 기준으로 생성한다. 새 PR에는 디자인 위에 작성한 기능 변경만 포함된다. 병합 후보 트리와 검증한 트리가 동일한지 확인하고 merge commit으로 병합한다. feature 브랜치/기존 worktree는 보존하고 force push/reset은 사용하지 않는다.
