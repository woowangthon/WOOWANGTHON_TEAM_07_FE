이전 테스트 중 세로 배치/보조 원본 이름/좌상·우하 요약을 기대하던 항목은 최신 요구사항으로 갱신했다. 원본은 `*.before-current-layout.js`로 보존했다. 필터 터치는 고정 x=300 대신 실제 스크롤 영역 내부에서 시작하고, DOMRect는 직렬화 가능한 수치 객체로 반환하도록 고쳤다. 44px 검사는 Chromium 부동소수 결과 43.999992px를 고려해 0.01px 오차만 허용한다. 제품 치수는 44px 그대로다.

## 남은 범위

- PR은 사용자 승인 없이 병합하지 않았다. 순서는 #48 → #61이며 #61은 #48을 base로 유지한다.
- #55의 커스텀 환승역 선택, REQ-ELV-001 전체 필터 개편, #57 목록 디자인은 미완료다. 완료로 닫지 않는다.

- 후속 백엔드 인증/즐겨찾기 실제 API 연결과 React/react-icons 이관은 이번 범위 밖이다.
