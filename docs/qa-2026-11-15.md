## 검증의 한계와 다음 연동

FE가 검사하는 것은 공급된 근거의 구조·최신성·연결·요청 대상·필수 설비 상태와 표시 우선순위다. 실제 방향별 열차 운행·반대 승강장 무계단 연결·환승 설비·출구에서 최종 목적지까지 이동 가능 여부는 공급자가 확인해야 한다. `source: API` 자체가 인증이나 물리적 안전성의 독립 증명이 되지는 않는다. 경로 탐색/실시간 설비 조회는 미연동이다.

백엔드에 필요한 필드는 [협의용 API 문서](accessible-route-api-proposal.md)에 정리했다. 백엔드 코드·worktree·Issue·PR은 수정하지 않았다. Chromium 이외 브라우저, 실제 이동·열차 운행은 이번 검증 범위 밖이다.
